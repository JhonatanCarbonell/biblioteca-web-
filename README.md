## Descripción
Este proyecto corresponde al **proyecto final del programa ADSO en el SENA**, desarrollado como evidencia **GA7-220501096-AA3-EV01**.  
El objetivo es implementar una aplicación web utilizando un framework moderno (Express.js) que permita transformar una interfaz estática en un módulo funcional, aplicando estándares de codificación, control de versiones y buenas prácticas de desarrollo

## Tecnologías utilizadas
- HTML5  
- CSS3  
- Node.js  
- Express.js  
- GitHub (versionamiento)  
- Figma (prototipo)  

## Instalación y ejecución
1. Clonar el repositorio:
   git clone https://github.com/usuario/windcode-explory.git
2. Instalar dependencias:
   npm install
3. Ejecutar el servidor:
   node server.js
4. Abrir en el navegador:
   http://localhost:3000
